# Requirement

**Project Code:** 10281 — Employee Performance Analysis
**Client:** INX Future Inc.
**Certification:** IABAC™ Certified Data Scientist

## Background

INX Future Inc. is a 15+ year data analytics and automation solutions provider, consistently
rated a top-20 employer. In recent years its employee performance indexes have declined,
service-delivery escalations have increased, and client satisfaction has dropped by 8
percentage points. The CEO wants the underlying causes identified via data analysis — without
resorting to blanket penalization that could damage morale or the company's reputation as an
employer of choice.

## Data Provided

`INX_Future_Inc_Employee_Performance_CDS_Project2_Data_V1_8.xls` — 1200 employee records, 28
attributes covering demographics, job role, compensation-related signals (salary hike %,
hourly rate), satisfaction/engagement ratings, tenure, training, and the target variable,
`PerformanceRating` (values: 2 = Good, 3 = Excellent, 4 = Outstanding).

## Requested Deliverables

1. Department-wise performance analysis.
2. Top 3 most important factors affecting employee performance.
3. A trained model that predicts an employee's performance rating from their attributes, for
   use in hiring decisions.
4. Recommendations to improve employee performance, grounded in the analysis.

## Submission Requirements (per IABAC™ Guidelines V1.2)

- Deliverables as Jupyter notebooks with markdown documentation.
- Project directory structured per the IABAC™ template (Project Summary / data / src / references).
- A written summary covering: algorithm and training method(s) used, feature selection/engineering
  rationale, and results/analysis/business insights.
